时刻 v0.1.1，Windows x64。

- 截图工具栏新增 **矩形、窗口、全屏、任意形状** 四种模式，支持按 1–4 切换、Esc 取消。
- 矩形可跨显示器，全屏捕获所有显示器；任意形状保存透明背景 PNG。
- 窗口模式悬停高亮、单击选取，捕获实际窗口，避免混入遮挡窗口。
- 滚动截图改为 **自动滚动、自动拼接**。框选内容后，你只需点击“结束并保存”或按 Ctrl + Shift + F；到达底部会自动保存。
- 焦点切换、鼠标离开捕获区域、窗口移动或无法可靠拼接时，停止自动滚动并保存已捕获部分。

下载 ZIP，完整解压后运行 `Shike.exe`。包含 .NET、Windows App SDK 和 Visual C++ 运行库；附 SHA-256。要求 Windows 10 2004+ / Windows 11 x64。

已通过 27 项核心断言，以及 Windows 11 / 125% 缩放下的程序内截图、窗口遮挡隔离、透明 PNG、真实滚轮自动滚动与拼接、停止保护和 MP4 回归自检。GitHub 构建和发布包启动检查随发布运行。

自动长截图仍为实验功能，请框选稳定的滚动内容并避开固定标题、动画。混合 DPI、多种第三方应用和音频设备仍需更多实测。当前没有代码签名、安装程序或 ARM64 原生包。
