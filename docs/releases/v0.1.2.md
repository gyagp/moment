时刻 v0.1.2 · 内容库与界面更新

- 新增内容库：自动发现已有截图和录屏，支持缩略图网格、名称搜索、图片/视频筛选，以及时间、名称、大小排序。
- 图片可缩放预览，录屏可在软件内播放，默认不自动播放。完成捕获后会自动定位到新文件。
- 支持重命名、复制图片/视频文件、打开文件和所在位置。
- 新增“最近删除”：可恢复内容，重启后仍有效；永久删除需要再次确认，恢复不会覆盖同名文件。
- 重做界面：固定侧栏、统一绿色配色、紧凑捕获工作区、独立内容预览面板。
- 外部文件新增、重命名和删除会刷新内容库。

Windows x64 ZIP 完整解压后运行 `Shike.exe`。包含运行库，附 SHA-256；发布包未做代码签名。

验证：52 项核心断言、WinUI 构建、内容库专项集成测试及实际渲染检查。内容库测试使用隔离文件，不操作用户现有内容。自动滚动截图仍为实验功能，固定页头、动画和混合 DPI 等场景需要更多实测。
