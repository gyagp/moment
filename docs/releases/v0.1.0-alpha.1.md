时刻的首个 Windows x64 预览版，使用 C# / WinUI 3 / Windows App SDK。

- 区域截图、PNG 保存、预览与复制图片。
- 实验性滚动截图：手动向下滚动，自动拼接重叠内容。
- 显示器录屏：H.264 MP4、30 fps、暂停/继续、可选系统声音和麦克风。
- 全局快捷键与结束捕获的浮动条。

下载 ZIP 后完整解压，运行 `Shike.exe`。附有 SHA-256 校验文件；包内包含 .NET、WinUI 和 Visual C++ 运行库。要求 Windows 10 2004+ / Windows 11 x64；N/KN 版本需 Media Feature Pack。

这是未签名的早期预览版。滚动截图不支持固定标题、动画和快速跳页，请缓慢向下滚动并检查结果。暂不支持标注、区域录屏、托盘、安装包或 ARM64 原生构建。

已验证核心拼接测试，以及 Windows 11、125% 缩放下的程序内 PNG、真实渲染滚动拼接、无声 MP4 暂停/继续/保存和视频帧解码。鼠标框选、多显示器混合 DPI、音频设备与干净系统仍需更多人工验证。详见仓库 `docs/validation.md`。
