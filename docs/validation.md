# 验证与已知限制

## 已有验证

- Release 构建无警告、无错误。
- 52 项核心断言：原有截图/滚动几何与拼接测试，以及内容库发现/筛选/排序、路径约束、Windows 文件名校验、同名不覆盖、删除后重启恢复、恢复冲突和永久删除范围保护。
- Windows 11 / x64 / 125% 缩放下的程序内集成自检：矩形、窗口、全屏、任意形状选择及取消；PNG alpha 读回；遮挡窗口不进入实际 HWND 截图；最小化窗口过滤；真实滚轮输入驱动 WinUI 页面自动滚动并拼接、底部检测、取消与焦点变化时拒绝继续输入；MP4 暂停/继续/保存和视频帧解码。
- v0.1.2 内容库专项自检：历史内容发现、图片预览、视频筛选及内嵌播放（默认不播放）、释放媒体句柄后重命名、最近删除/恢复、外部文件变更刷新、空搜索结果。仅使用隔离的测试文件。

在有交互桌面的机器运行集成诊断（测试会短暂显示窗口和录制无声测试画面）：

```powershell
./artifacts/publish/Shike.exe --smoke-test ./artifacts/smoke
```

查看输出目录中的 `result.txt`；成功退出码为 0。`ui.png` 是主窗口捕获，`selection-toolbar.png` 是截图工具栏，另有透明 PNG、窗口截图、自动长图、测试 MP4 和媒体属性。测试会自动操作测试窗口内的滚轮；测试输出不应提交。应保持测试窗口可见，避免其他置顶窗口干扰。

## 尚需人工验证

- 人工鼠标/触摸拖动、键盘模式切换及 Esc、全局快捷键冲突、复制到其他程序。程序内测试覆盖共享选择逻辑，没有替代全部外部输入测试。
- 混合 DPI、多显示器（特别是负坐标）、显示器热插拔。
- 浏览器、PDF、编辑器中的真实自动滚动，固定标题、滚轮惯性、跳页和动画场景。
- 系统声音、麦克风权限和设备切换、长时间录屏、磁盘不足、睡眠恢复。
- 不含预装运行时的干净 Windows 10 / 11 环境。

当前环境的 computer-use native pipe 不可用，因此未宣称自动化完成上述鼠标交互测试。

内容库与界面的验证可独立运行，不需要让时刻占用桌面前台：

```powershell
./artifacts/publish/Shike.exe --library-test ./artifacts/library-test
```

它用 WinUI `RenderTargetBitmap` 渲染自身控件，生成 `ui.png`、`library.png` 供视觉检查，并创建无声测试视频。完整 `--smoke-test` 仍需要测试窗口保持前台；v0.1.2 的一次完整回归因前台画面属于其他窗口而中止，内容库改用独立渲染流程验证。v0.1.1 的捕获完整回归结果保留，不能将内容库专项测试等同于所有截图交互均已复测。

## 当前限制

- 录屏范围为整个所选显示器；区域录屏尚未暴露到界面。
- 自动滚动截图仅支持向下、保留明显重叠、内容稳定的场景；不处理固定页头。目标需能响应滚轮，不能是更高权限或受保护的窗口。匹配失败时保存已完成部分，提示停止原因。
- 窗口模式无法捕获已最小化、已关闭或阻止捕获的窗口；窗口被选中后若内容变化，保存的是其随后返回的当前画面。
- 无截图标注、托盘、自定义快捷键或设置持久化。
- DRM 视频、受保护窗口、UAC 安全桌面可能为黑屏，遵循 Windows 限制。
- 没有代码签名和安装程序；发布包仅 x64。
- 浮动条的捕获排除依赖 Windows API；第三方捕获软件不保证遵循。
