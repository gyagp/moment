# 验证与已知限制

## 已有验证

- Release 构建无警告、无错误。
- 核心测试：多段滚动逐像素重建、重复帧、无关画面、向上滚动拒绝、大小边界。
- Windows 11 / x64 / 125% 缩放下的程序内集成自检：WinUI 窗口、原生屏幕捕获、真实渲染内容的滚动拼接、PNG 编码/解码、MP4 录制/暂停/继续/停止、元数据与视频帧解码。

在有交互桌面的机器运行集成诊断（测试会短暂显示窗口和录制无声测试画面）：

```powershell
./artifacts/publish/Shike.exe --smoke-test ./artifacts/smoke
```

查看输出目录中的 `result.txt`；成功退出码为 0。`ui.png` 是主窗口的捕获，另有长图、测试 MP4 和媒体属性。测试输出不应提交到仓库。测试窗口应保持可见，避免其他置顶窗口覆盖。

## 尚需人工验证

- 鼠标框选、Esc 取消、全局快捷键冲突、复制到其他程序。
- 混合 DPI、多显示器（特别是负坐标）、显示器热插拔。
- 浏览器、PDF、编辑器中的真实长页面，固定标题与动画场景。
- 系统声音、麦克风权限和设备切换、长时间录屏、磁盘不足、睡眠恢复。
- 不含预装运行时的干净 Windows 10 / 11 环境。

当前环境的 computer-use native pipe 不可用，因此未宣称自动化完成上述鼠标交互测试。

## 预览版限制

- 录屏范围为整个所选显示器；区域录屏尚未暴露到界面。
- 滚动截图仅支持向下、保留明显重叠、内容稳定的场景；不处理固定页头，也不会自动滚动。
- 无截图标注、托盘、自定义快捷键或设置持久化。
- DRM 视频、受保护窗口、UAC 安全桌面可能为黑屏，遵循 Windows 限制。
- 没有代码签名和安装程序；发布包仅 x64。
- 浮动条的捕获排除依赖 Windows API；第三方捕获软件不保证遵循。
