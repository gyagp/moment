# v0.1.2 界面设计

目标：将时刻从大尺寸功能卡片首页调整为适合日常使用的桌面工具，统一捕获与内容管理。

- 固定深绿色侧栏承载品牌、捕获/内容库导航和常用快捷键。
- 浅色工作区采用低对比度边框、统一圆角、深绿文字和绿色主要操作。
- 捕获页以新建截图为主要入口，自动长截图和录屏为紧凑的辅助操作，显示器/音频设置集中放在下方。
- 内容库采用缩略图网格与独立详情面板，文件操作靠近预览，搜索、分类和排序固定在顶部。
- 普通图片初始适应预览区域，长图优先适应宽度；视频不自动播放。
- 实现均为 WinUI XAML 和原生媒体控件，设计图不作为 UI 背景或交互替代品。

用户指定通过 `GOOGLE_API_KEY` 调用 Nano Banana。已从环境变量读取密钥，分别请求 Google 模型列表及 `gemini-2.5-flash-image:generateContent`；均返回 HTTP 400 `FAILED_PRECONDITION: User location is not supported for the API use.`，因此未生成或使用 Nano Banana 图片，也未将截图上传到 Google。密钥没有写入项目或日志。

提交的文字提示要求：为“时刻 / Shike”设计高保真 Windows 原生内容库；深绿固定侧栏、浅色工作区、缩略图网格、搜索/类型筛选和独立预览；重命名、复制、打开和最近删除操作；简体中文、克制的字号与间距、细边框、绿色重点色；不增加营销大图、分析图表或无关功能。原始提示保存在本地 `artifacts/design/nano-banana-prompt.txt`。

视觉验证使用应用自身控件树渲染的截图。生成方式及输出文件参见 `docs/validation.md` 的 `--library-test`。
